Русский ↔ китайский идёт через английский: ru→zh = ru-en, затем en-zh; zh→ru = zh-en, затем en-ru.

## Как получить
Скачать архив, сверить SHA-256 с манифестом, распаковать. Распаковывать только нужные файлы.

## Происхождение и лицензия
Веса: Helsinki-NLP, модели Opus-MT, лицензия CC-BY-4.0. Конвертация в ONNX и квантование в int8 сделаны в проекте RussSearchOPPO.

## Как пересобрать (для любого ИИ или человека)
1. Экспорт в ONNX: `optimum-cli export onnx --model Helsinki-NLP/opus-mt-<пара> --task text2text-generation-with-past <папка>`, где пара: ru-en, en-ru, zh-en, en-zh.
2. Квантование int8: `onnxruntime` dynamic quantization с `--avx2`.
3. Проверка: перевод короткой фразы и сравнение с ожидаемым словом (разрешён список слов на пару).
4. Упаковка в zip, SHA-256, обновление манифеста.
Точные команды и порядок — в приватном репозитории RussSearchOPPO (workflow «Build offline translation models», docs/hive/ml-translation).

## Статус
Архивы ещё не загружены в релиз `translation-models-v1` (владелец загружает вручную). Тег должен указывать на этот репозиторий, ветку main.

Код приложения находится в приватном репозитории RussSearchOPPO и не публикуется здесь. Карта проекта для продолжения работы: `docs/hive/WHERE-IS-WHAT.md` в RussSearchOPPO.
